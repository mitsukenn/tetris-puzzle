# 🧩 テトリスパズル

8×8の盤面にテトリス風ブロックをドラッグ＆ドロップで配置し、縦・横の列を揃えて消していくパズルゲームです。

## 🎮 あそびかた

**▶ プレイはこちら → https://machino-ai.jp/tetris-puzzle/**

- 下のトレイからブロックをドラッグして盤面に置きます
- 縦1列・横1列が揃うと、その列が消えて得点になります
- 複数列の同時消しや連続消し（コンボ）でボーナス得点
- 3つのブロックを使い切ると次の3つが補充されます
- どのブロックも置けなくなったらゲームオーバー

## 🏆 ゲームモード

目標スコアに到達すると「クリア」となり、クリア回数に応じて新しいモードが解放されます。

| モード | 内容 | 解放条件 |
|---|---|---|
| 🧩 通常 | じっくりハイスコアを狙う | 最初から遊べる |
| ⏱️ タイムアタック | 3分間の時間制限つき | 合計3回クリア |
| 🔥 ハード | 小さいピースが出にくい | 合計5回クリア |
| 💀 ベリーハード | 大型ピース中心＋お邪魔ブロック | 合計10回クリア |

クリア回数は**どのモードでプレイした分も合計にカウント**されます。

モード選択画面の「📊 スコア記録」から、過去7日間の1日ごとのベストスコアをグラフで確認できます（モード別の表示切替つき）。

スマホ・タブレット・PCのブラウザでそのまま遊べます。

## 📱 ホーム画面に追加（PWA対応）

スマホのブラウザでメニューから「**ホーム画面に追加**」を選ぶと、アプリのようにアイコンから全画面で起動できます。オフラインでもプレイ可能です。
